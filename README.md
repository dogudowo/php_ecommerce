

 # public_html 專案說明
 
 此資料夾為網站專案的根目錄，部署於遠端伺服器上。以下是此專案的基本結構與用途說明：
 
 ## 📁 資料夾結構
 
 ```
 public_html/
 ├── index.php       # 首頁
 ├── nav.php         # navbar
 ├── footer.php      # 頁腳
 ├── information.php # 購物說明
 ├── introduce.php   # 品牌介紹
 ├── repair.php      # 保固維修
 ├── QandA.php       # Q & A
 ├──
 ├──
 ├── imgs             # 圖片資源
 └── README.md        # 專案說明文件（本檔案）
 ```
 
 ## 🚀 部署方式
 
 1. 確定本檔案夾在XAMPP開啟之資料夾路徑
 2. 使用XAMPP開啟
